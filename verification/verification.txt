# Verification

This project includes verification evidence captured from Cisco Packet Tracer.

## LACP EtherChannel — Core

Command:

```text
show etherchannel summary
```

Observed result:

```text
Group  Port-channel  Protocol  Ports
1      Po1(SU)       LACP      Fa0/2(P) Fa0/6(P)
2      Po2(SU)       LACP      Fa0/3(P) Fa0/7(P)
```

`LACP` confirms LACP negotiation, `SU` shows the Layer-2 port-channel is in use, and `(P)` shows the physical interfaces are successfully bundled.

## Notes

- DHCP Snooping was not enabled globally on SW1/SW2; only the access-port rate-limit command is present in the supplied configurations.
- PC13 is used only for Port Security testing and is not treated as a normal production client in the topology documentation.
